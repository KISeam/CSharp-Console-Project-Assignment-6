# C-Console-Project-Assignment-6

A simple C# console application developed using .NET 10.0.  
This project generates a multiplication table for a user-provided number using both `for` loop and `while` loop.

---

## 📌 Project Overview

The application takes a single integer input from the user and prints its multiplication table from 1 to 10.

It demonstrates:

- `for` loop usage
- `while` loop usage
- Basic console input/output handling
- Iteration and repetition concepts in C#

---

## 🛠 Technologies Used

- C#
- .NET 10.0 SDK
